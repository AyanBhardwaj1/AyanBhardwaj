# OG card fonts

Static WOFF subsets (Latin) used only by `src/lib/og.tsx` to render share
images at build time. Satori cannot read WOFF2, so these come from the
`@fontsource/archivo` and `@fontsource/ibm-plex-mono` packages.

Both families are licensed under the SIL Open Font License 1.1
(<https://openfontlicense.org>). Archivo: Omnibus-Type. IBM Plex Mono: IBM.
